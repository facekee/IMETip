## 3. 手工验证步骤（推荐顺序）

1. **基础**：启动程序 → 检查托盘图标与 Tooltip → 打开记事本点击编辑区 → 观察 5 秒后消失。
2. **状态**：在记事本内按 Caps Lock、Ctrl+Space，确认刷新与重新计时。
3. **会话**：等待指示窗消失后再次点击同一输入框（不应弹出）；点击另一个输入框（应弹出一次）。
4. **边界**：把记事本拖到屏幕最上方 / 最右侧，点击靠近边缘的输入框，确认指示窗翻转后完整可见。
5. **多屏 / DPI**：在 150% 与 100% 显示器间移动窗口，重复步骤 1。
6. **浏览器**：在 Chrome 地址栏、搜索框、网页正文分别点击，确认显示 / 不显示。
7. **终端**：在 Windows Terminal 中点击命令行，确认 UIA 回退生效。
8. **暂停 / 退出**：托盘暂停后确认不再显示；退出后确认托盘图标消失。
9. **资源**：任务管理器观察 10 分钟，确认 CPU 为 0、内存稳定在 4 MB 左右。
