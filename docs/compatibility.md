# 兼容性与已知限制

## 1. 支持范围

| 项目 | 范围 |
| --- | --- |
| 操作系统 | Windows 10 1903 及以上、Windows 11，x64 |
| 权限 | 普通用户（`asInvoker`），无需管理员 |
| 显示 | 单屏 / 多屏，100%–300% 缩放，混合 DPI |
| 输入法 | 微软拼音、搜狗拼音、QQ 拼音等以语言掩码暴露状态的中文输入法 |
| 应用 | 记事本、Chrome、Edge、Windows Terminal、Office、常见 Win32/WinUI 文本框 |

## 2. 检测策略与降级

| 场景 | 主路径 | 回退 | 结果 |
| --- | --- | --- | --- |
| 标准 Win32 编辑框（记事本、Office、对话框） | `GetGUIThreadInfo` 光标矩形 | — | 正常显示 |
| 浏览器（Chrome / Edge） | 标准光标常不可用 | UI Automation 文本选区 | 正常显示（UIA 可用时） |
| Windows Terminal | 标准光标不可用 | UI Automation 文本模式 | 正常显示 |
| 现代 TSF 应用（微信 / 新版记事本 / WPS） | 无 IMM 上下文 | 默认 IME 窗口 `WM_IME_CONTROL` | 中英文状态可读（标记 `viaFallback`） |
| 点击后异步创建光标的应用（微信） | 首次探测未命中 | 150ms 后一次性复查 | 单击即可显示 |
| 窗口滚动（滚轮 / 翻页 / 拖动滚动条） | `EVENT_SYSTEM_SCROLLINGSTART` 等 | — | 立即隐藏 |
| UIA 查询超时（>50 ms） | — | 放弃本次判定 | 不显示，不影响输入 |
| 只读文本 / 网页正文 | — | `UIA_IsReadOnlyAttributeId=true` | 不显示 |
| 只读标准 Edit 控件 | `ES_READONLY` 样式判断 | — | 不显示 |
| 非中文键盘布局 | `GetKeyboardLayout` 语言判断 | — | 判定英文，不查询 IME |
| IME 上下文不可用 | 默认 IME 窗口 | 沿用上次有效状态 | 不崩溃、不弹窗 |
| 高权限窗口（管理员程序） | 低权限进程可能无法读取焦点信息 | — | 可能不显示，属预期限制 |

## 3. 已知限制

1. **只区分中文 / 非中文**：日文、韩文输入法会被判定为“英”。产品定位为中英提示，如需扩展需引入语言维度。
2. **浏览器内容可编辑区域的判定依赖 UIA 属性**：极少数网页编辑器可能把可编辑区域报告为只读（或反之），可能出现该显示时不显示 / 不该显示时显示。
3. **同一顶层窗口内的多个输入框视为同一会话**：Chrome 中点击不同输入框不会重新弹出（会话标识使用焦点 HWND，浏览器焦点 HWND 是顶层窗口）。同一输入框内状态未变化时同样不重复弹出，符合 PRD。
4. **WPS 表格单元格编辑不显示**：WPS 在单元格内编辑时既没有标准光标（`GetGUIThreadInfo` 返回空），也没有 UIA 文本选区，无法可靠定位光标。按 PRD「不支持标准光标且 UIA 也失败时不显示」处理。
5. **Shift 轻点即可触发复查**：每次 Shift 抬起都会复查一次状态，因此输入大写字母时会产生一次额外的 IME 查询（仍在 50ms 去抖窗口内合并）。
6. **TSF 应用的状态依赖输入法自身实现**：`WM_IME_CONTROL` 回退路径由输入法响应，若输入法不响应则沿用上次状态；日志中 `viaFallback` 可区分来源。
7. **UWP / WinUI 应用**：依赖 UI Automation，首次查询可能略慢（受应用响应速度影响）。
8. **不使用标准光标且 UIA 也失败的应用**：不显示提示，属 PRD 允许的降级。
9. **低级钩子可能被安全软件拦截**：钩子注册失败时程序通过托盘气泡提示“运行受限”，不会静默改为轮询。
10. **远程桌面 / 锁屏状态**：锁屏或未连接会话中无法获取真实前台输入控件，指示窗不会出现。

## 4. 隐私与安全

| 项目 | 实现 |
| --- | --- |
| 网络 | 无任何 socket / HTTP 调用，不链接 WinINet/WinHTTP |
| 输入内容 | 不读取、不缓存、不落盘；低级键盘钩子只判断按键类型与是否注入，不保存键值序列 |
| 目标进程 | 不注入、不修改、不发送输入；只做只读查询（`GetGUIThreadInfo`、`ImmGetContext`、UIA） |
| 权限 | `asInvoker`，不请求管理员 |
| 配置 | 仅保存显示时长、偏移、淡出等界面参数 |
| 日志 | 默认关闭；开启后只记录生命周期与“显示/隐藏”状态，不含任何文本内容 |
